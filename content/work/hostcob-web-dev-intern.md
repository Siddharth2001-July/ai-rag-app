# Web Development Intern at Hostcob Solutions

**Company:** Hostcob Solutions Private Limited
**Role:** Web Development Intern
**Dates:** August 2021 – October 2021
**Location:** Dehradun, Uttarakhand, India

Siddharth's first professional engineering experience — a 3-month web development internship while he was still in his B.Tech program.

## What he built: HeavenlyUttarakhand

A user-friendly tourism website for Uttarakhand, built from scratch. It let visitors explore the state's tourist destinations with district-wise listings for navigation. Siddharth led the implementation across both the front-end and back-end.

## Tech stack

- **Front-end:** Bootstrap (v4/v5), CSS (v4), HTML5, jQuery, DOM, JavaScript
- **Back-end:** MySQL, Node.js, Express.js

## What this gave him

This was where Siddharth picked up the fundamentals of full-stack web development — moving content between a database, an Express.js back-end, and a Bootstrap-themed front-end. The experience set the foundation for the more sophisticated full-stack work he'd later do at Techbit and Nutrient.
